# Shakr Media

> Shakr is a video creation platform that lets businesses produce and automate video at scale. The Shakr Video API (v2) provides programmatic end-to-end video production — build a creative template, map input content onto it, render, and auto-deliver to destinations like Amazon S3, Azure Blob Storage, and Facebook Ad Accounts. The Shakr Video Editor SDK embeds a white-labeled drag-and-drop video editor directly inside a customer's product. Authentication is OAuth 2.0 Client Credentials with bearer tokens. Shakr is a 500 Global portfolio company.

## APIs

- [Shakr Video API (v2)](https://developers.shakr.com/docs/api/introduction/): REST API for programmatic video creation. Base URL https://api.shakr.com/v2/. Resources: TemplateStyleVersion, Mapping, RenderSession.
- [Shakr Video Editor SDK](https://developers.shakr.com/docs/editor-sdk/introduction/): Embeddable white-label drag-and-drop video editor (npm @shakrmedia/editor-sdk).
